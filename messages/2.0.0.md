Breaking changes:

- The key used to override LSP-nimlangserver settings in project settings has changed from `nimlangserver` to `LSP-nimlangserver`.
  If you use project-specific overrides for LSP-nimlangserver, you have to rename the key for them to apply:

  Before:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "nimlangserver": {
                  // ...
              }
          }
      }
  }
  ```

  After:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "LSP-nimlangserver": {
                  // ...
              }
          }
      }
  }
  ```
